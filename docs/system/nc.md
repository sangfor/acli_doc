# nc

### 操作概述

探测指定主机和端口的连通性，可显示目标服务返回的信息。

### 命令参数

命令格式：

```bash
acli system nc [-w seconds] [-i seconds] <host> <port>
```

支持的参数：

本命令采用封闭式探测参数白名单（未列举即拒绝）。仅支持取值型短选项 `-w`、`-i`。

```text
-w <秒>    指定等待时间，值须为数字
-i <秒>    指定时间间隔，值须为数字
<host>     必要参数，目标主机，须满足允许的字符集
<port>     必要参数，目标端口，范围 1-65535
```

位置参数必须恰好为 `<host> <port>` 两个，额外位置参数拒绝。

设备使用 BusyBox nc，不支持独立的 `-z`、`-v`。封装层将标准输入连接到 `/dev/null`，并在指定 `-w` 时以 `-w` 值加 2 秒设置兜底超时，将调用限制为探测；连接建立后退出，并依据退出码反馈连通、超时或不连通。

禁止清单：

```text
-l    监听模式
-e    执行程序
-f    读取文件（部分 nc 实现支持）
-p    指定本地端口
```

其他白名单外短选项（包括 `-z`、`-v`）及所有长选项一律拒绝。拒绝时返回人类可读的原因及非零退出码，不泄露敏感路径或内部实现细节。

### 使用示例

```bash
acli system nc -w 3 127.0.0.1 22
```

### 结果示例

```text
SSH-2.0-OpenSSH_SangforOS
```
