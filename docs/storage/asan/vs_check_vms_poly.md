# vs_check_vms_poly

### 操作概述

执行虚拟机磁盘 POLY 状态的只读检查。

### 命令参数

命令格式：

```bash
acli storage asan vs_check_vms_poly [options]
```

支持的参数：

本命令采用封闭式参数白名单（未列举即拒绝），仅放通只读检查执行。写类参数和写子命令一律拒绝。

布尔选项白名单：

```text
-a|--all
-d|--detail
-p|--poly
```

取值选项白名单：

```text
-v|--vmid=string    指定虚拟机 ID
-f|--file=string    指定文件
-g|--gfid=string    指定 GFID
-t|--tid=string     指定 TID
-n|--name=string    指定名称
```

支持短选项传值和 GNU 长选项的 `=` 写法，例如 `-v 343999323256` 或 `--vmid=343999323256`。位置参数一律拒绝，检查对象必须通过选项指定。

禁止清单：

位置参数、写类参数、写子命令及白名单外选项一律拒绝。

### 使用示例

```bash
acli storage asan vs_check_vms_poly -v 343999323256
```
