# list

### 操作概述

查询集群 PCI 设备列表

### 命令参数

```bash
-h|--host-ids=string              按主机ID过滤，需传JSON数组格式，示例：['host-0050568ec35e']
-i|--ids=string                   按设备ID过滤，需传JSON数组格式，示例：['0000:1b:00.0']
-n|--name=string                  按设备名称过滤，示例：eth5
-s|--status=string                按设备状态过滤，可选值：Offline（离线）、Normal（正常）。枚举=['Offline', 'Normal']
-t|--type=string                  按设备类型过滤，可选值：iface（网卡）、encryption（加密卡）。枚举=['iface', 'encryption']
-m|--model=string                 按设备型号过滤，示例：VMware VMXNET3 Ethernet Controller
-M|--mode=string                  按设备模式过滤，可选值：vf（虚拟功能）、passthrough（直通）、pf（物理功能）、none（未配置）。枚举=['vf', 'passthrough', 'pf', 'none']
--submodule=string                指定加入列表的子模块类型，可选值：pf、vf、pci。枚举=['pf', 'vf', 'pci']
-e|--excludable-submodule=string  指定无法加入列表的子模块类型，可选值：pf、vf、pci。枚举=['pf', 'vf', 'pci']
-E|--enable=boolean               是否仅返回已启用的设备
-u|--use-cache=boolean            是否使用缓存（不传默认使用缓存；传0/false则实时查询）
--start=integer                   分页起始位置（从0开始，最小0）；与--limit配合使用，需同时传入
-l|--limit=integer                分页每页数量（最大50）；与--start配合使用，需同时传入
-k|--keyword=string               PCI设备模糊匹配关键字，示例：eth
-S|--sort=string                  排序字段（默认按name排序），可选值：status、type、slot、mode、relatedVMS。枚举=['status', 'type', 'slot', 'mode', 'relatedVMS']
-d|--direct=string                排序方向，可选值：ASC（升序）、DESC（降序）；需与--sort配合使用。枚举=['ASC', 'DESC']
```

### 使用示例

```bash
acli hardware pcie list
acli hardware pcie list --host-ids '["host-0050568ec35e"]' --type iface --status Normal
```
