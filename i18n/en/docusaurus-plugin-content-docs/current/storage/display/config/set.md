# set

### Overview

Set whether to display Local system disks with available space >= 100G

### Command Parameters

```bash
-a|--allow-small-local-disk=integer    Required parameter, whether to display Local system disks with available space >= 100G, Required enumeration values: 0 (do not display), 1 (display)
```

### Usage Example

```bash
acli storage display config set -a 1
```

### Output Example

```bash
Command executed successfully!
```
