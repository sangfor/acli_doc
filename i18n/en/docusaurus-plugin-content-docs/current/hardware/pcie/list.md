# list

### Overview

List cluster PCI devices

### Command Parameters

```bash
-h|--host-ids=string               Filter by host IDs; JSON array format required
-i|--ids=string                    Filter by device IDs; JSON array format required
-n|--name=string                   Filter by device name, example: eth5
-s|--status=string                 Filter by device status. Values: Offline (offline), Normal (normal). enum=['Offline', 'Normal']
-t|--type=string                   Filter by device type. Values: iface (network card), encryption (encryption card). enum=['iface', 'encryption']
-m|--model=string                  Filter by device model, example: VMware VMXNET3 Ethernet Controller
-M|--mode=string                   Filter by device mode. Values: vf (virtual function), passthrough (passthrough), pf (physical function), none (not configured). enum=['vf', 'passthrough', 'pf', 'none']
--submodule=string                 Submodule type to include in the list. Values: pf, vf, pci. enum=['pf', 'vf', 'pci']
-e|--excludable-submodule=string   Submodule type that cannot be included in the list. Values: pf, vf, pci. enum=['pf', 'vf', 'pci']
-E|--enable=boolean                Whether to return only enabled devices
-u|--use-cache=boolean             Whether to use cache (default uses cache when omitted; 0/false triggers real-time query)
--start=integer                    Pagination start position (from 0, min 0); used with --limit, both must be provided together
-l|--limit=integer                 Page size (max 50); used with --start, both must be provided together
-k|--keyword=string                Fuzzy match keyword for PCI devices, example: eth
-S|--sort=string                   Sort field (defaults to name). Values: status, type, slot, mode, relatedVMS. enum=['status', 'type', 'slot', 'mode', 'relatedVMS']
-d|--direct=string                 Sort direction. Values: ASC (ascending), DESC (descending); used with --sort. enum=['ASC', 'DESC']
```

### Usage Example

```bash
acli hardware pcie list
acli hardware pcie list --host-ids '["host-0050568ec35e"]' --type iface --status Normal
```
