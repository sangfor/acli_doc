# uptime

### Overview

View system uptime, current time, number of logged-in users and system load (read-only).

### Command Parameters

no parameters

### Usage Example

```bash
acli system uptime
```

### Output Example

```bash
# acli system uptime
 10:30:01 up 128 days,  4:32,  1 user,  load average: 0.15, 0.08, 0.06
```
