# ibv_devices

### Overview

List available RDMA device names and their node GUIDs.

### Command Parameters

No parameters

### Usage Example

```bash
acli system ibv_devices
```

### Output Example

```text
    device                 node GUID
    ------              ----------------
```

This example shows only the table header, indicating that no available devices were listed by this query.
