# who

### Overview

View information about users currently logged into the system (read-only).

### Command Parameters

No parameters

### Usage Example

```bash
acli system who
```

### Output Example

```bash
# acli system who
root     pts/0        2026-09-08 10:20 (10.0.0.10)
admin    pts/1        2026-09-08 10:25 (10.0.0.11)
```
