# get

### Overview

Get syslog forwarding configuration

### Command Parameters

```bash
No parameters
```

### Usage Example

```bash
acli platform syslog config get
```

### Output Example

```bash
{
  "kernlog_enabled": "0",
  "lang": "zh_CN",
  "oplog_enabled": "0",
  "protocol": "tcp",
  "server_name": "",
  "server_port": "",
  "syslog_enabled": "0"
}
```
